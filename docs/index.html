Por que usar o SDD Agent Plugin?

Elimine o "vibe coding" e introduza rigor de engenharia diretamente nas conversas com o GitHub Copilot.

Orquestração via @sdd

Acione o orquestrador principal com @sdd. Ele delega para subagentes especializados sem poluir sua interface.

Visão Computacional

Arraste mockups e wireframes para o chat do VS Code para gerar especificações visuais exatas.

Rastreabilidade Total

Cada bloco de código gerado possui cabeçalhos vinculados às especificações de origem salvos na pasta `.sdd/`.

Gates de Qualidade & BDD

Geração automática de cenários BDD e verificação de convergência antes do commit.

Pipeline Metodológico

O Fluxo de Trabalho SDD

Fases estruturadas conduzidas inteiramente pelo agente @sdd no Copilot.

01

Specify

@sdd (Especificar)

Define requisitos e histórias de usuário (salvos em `.sdd/specs/`) através de diálogo.

02

Plan

@sdd (Planejar)

Gera arquitetura técnica e contratos (salvos em `.sdd/plans/`) antes de codificar.

03

Tasks

@sdd (Tarefas)

Divide o plano em subtarefas atômicas (salvas em `.sdd/tasks/`) otimizadas para IA.

04

Implement

@sdd (Implementar)

Executa a escrita de código com validação contínua e rastreabilidade nos artefatos.

Instalação no Visual Studio Code

Siga os passos abaixo para instalar o plugin diretamente da fonte no VS Code.

Passo a Passo de Instalação VS Code Preview
  1. 1
    Abra a Paleta de Comandos no VS Code pressionando Ctrl+Shift+P (Cmd+Shift+P no Mac).
  2. 2
    Execute o comando Chat: Install Plugin From Source.
  3. 3
    Cole a URL do seu repositório GitHub: https://github.com/airesvsg/sdd-vscode-copilot-plugin.
  4. 4
    Digite @sdd no Copilot Chat para iniciar o fluxo.
Nota: Certifique-se de que a configuração chat.plugins.enabled está habilitada no seu VS Code.
